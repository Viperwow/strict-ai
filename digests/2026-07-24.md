## 1) Top 5 AI tools

1. **Cursor Router (Auto)** — классификатор маршрутизирует запрос на подходящую модель (Intelligence / Balance / Cost). Early access: ~30–50% дешевле Opus 4.8 без потери качества; online A/B — до ~60% экономии. Effort: низкий (включить Auto). Impact: высокий на ежедневный coding bill. https://cursor.com/blog/router
2. **Claude Voice (Opus/Sonnet)** — голосовой режим больше не только Haiku: mid-convo switch моделей + tools (Gmail, Slack, Calendar, Notion). Effort: низкий. Impact: средний–высокий для thinking-out-loud / planning на ходу. https://claude.com/blog/think-through-hard-problems-in-voice-mode
3. **OpenAI Presence** — enterprise voice/chat agents с policy, симуляциями, escalation и Codex-улучшениями; не self-serve (FDE). Effort: высокий (enterprise). Impact: высокий, если строите production support agents. https://openai.com/index/introducing-openai-presence/
4. **Grok 4.5 API / Grok Build** — frontier-ish coding/agent model по агрессивной цене (~$2/$6 per 1M tok) + open harness. Effort: низкий–средний. Impact: высокий для cost-sensitive agent loops. https://choosely.ai/ai-radar/grok-4-5-ai-tool-changes-july-2026
5. **Gemini 3.6 Flash / 3.5 Flash-Lite** — workhorse + ultra-cheap tier; coding/efficiency ап; 3.5 Pro всё ещё delayed. Effort: низкий. Impact: высокий для high-volume agent backends. https://techcrunch.com/2026/07/21/google-releases-three-new-gemini-models-but-no-3-5-pro/

## 4) Top 5 trends

1. **Agent governance > raw model demos** — Presence, sims, guardrails, human escalation.
2. **Cost-aware model routing** — Cursor Router / OmniRoute; frontier только на hard path.
3. **Eval infrastructure for skills/agents** — AEVAL, AgentCompass, dense long-horizon benches.
4. **Open agent harnesses** — Grok Build, Hermes Agent, GenericAgent: loop/tools/memory важнее «ещё одной LLM».
5. **Voice + tools as work surface** — Claude Voice с Opus/Sonnet и app actions; Presence voice agents.

## 5) Top 5 papers (1-line takeaway)

1. **AEVAL** https://arxiv.org/abs/2607.16345 — deterministic skill tests: executor≠grader + first-attempt grading убивает self-fulfilling 100% pass.
2. **PoTRE** https://arxiv.org/abs/2607.20268 — heterogeneous multi-agent reasoning (4 specialists + aggregation) → SOTA ~49.92% HLE без раздувания tokens.
3. **Speculate with Memory** https://arxiv.org/abs/2607.12236 — memory-augmented speculative execution для agents: +19–39% action prediction, lossless (idle-time).
4. **OmniReasoner** https://arxiv.org/abs/2607.19339 — long A/V reasoning через native zoom-in tool + TimeAnchor (compute только на informative intervals).
5. **Long-Horizon-Terminal-Bench** https://arxiv.org/html/2607.08964v2 — dense partial rewards; даже Grok 4.5 ~28% @0.95 — long-horizon terminal всё ещё hard.
