# Evidence quality grades (A–E)

| Grade | Meaning |
|-------|---------|
| **A** | Strong primary data with an appropriate denominator and highly relevant event definition. |
| **B** | Good official or high-quality data but with some limitations in denominator, transferability, or completeness. |
| **C** | Useful but indirect evidence, substantial modeling assumptions, or incomplete reporting. |
| **D** | Weak anecdotal or media-only evidence. |
| **E** | Insufficient evidence for a meaningful quantitative estimate. |

Explain the grade briefly in every report.
