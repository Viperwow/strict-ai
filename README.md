# strict-ai

A curated set of Claude Code skills, rules, commands, and plugins for disciplined AI-assisted development.

## What’s inside

- **Skills** — repeatable workflows for analysis, refactoring, onboarding, and context management.
- **Commands** — slash commands for fast, focused actions.
- **Rules** — ESLint-like guidance for AI behavior and code quality.
- **Plugins** — separate extensions for specific workflows and integrations.

## Goal

Make Claude more structured, predictable, and useful for real software development.

## Status

Work in progress.
