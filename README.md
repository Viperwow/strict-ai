# strict-ai

A curated set of Claude Code plugins for disciplined software engineering — domain-separated packages for every phase of daily work and SDLC.

## Install

In Claude Code, run:

```
/plugin marketplace add Viperwow/strict-ai
/plugin install strict-workday@strict-ai
```

Swap `strict-workday` for any other available plugin from this marketplace. Update later with `/plugin marketplace update strict-ai`.

## Plugins

| Plugin | Purpose |
|:---|:---|
| `strict-workday` | Daily rhythm, focus, time management |
| `strict-communication` | Drafting, Slack/email, summaries |
| `strict-development` | Implementation, architecture, PR prep |
| `strict-management` | Planning, decomposition, backlog |
| `strict-quality` | Testing, verification, quality gates |
| `strict-security` | Security review, secure design, secrets |
| `strict-workflows` | Composed end-to-end SDLC workflows |
| `strict-knowledge` | Playbooks, internal procedures |
| `strict-foundation` | Shared primitives across packages |
| `strict-adapters` | Tool-specific adapters (Jira, Slack, etc.) |
| `strict-labs` | Experimental — under development |
| `strict-deprecated` | Pending removal — see replacement in each |

> **Available in marketplace:** `strict-workday` · `strict-labs`
> All other plugins are actively being developed and will be released to the marketplace over time.
